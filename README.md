# Travel Guide - AI Audio Guide

Live demo: https://travel-guide-p5gq.onrender.com

(Free hosting: the first request can take up to 1 minute while the server wakes up.)

A web app that generates a spoken travel guide for famous Indian landmarks.

## Features
- Choose a place, a summary or detailed guide, a language and a voice
- Text generated by Google Gemini
- Speech generated by Murf AI
- Languages: English, Hindi, Tamil, Telugu
- Male and female voices

## Tech Stack
- Frontend: HTML, Tailwind CSS, JavaScript
- Backend: Python, Flask
- AI: Google Gemini API, Murf AI API
- Hosting: Render

## How to run locally
1. Go to the Backend folder.
2. Create a `.env` file with:
   GEMINI_API_KEY=your_key
   MURF_API_KEY=your_key
   GEMINI_MODEL=gemini-2.5-flash
3. Install packages: pip install -r requirements.txt
4. Run: python app.py
5. Open Frontend/index.html in your browser.
